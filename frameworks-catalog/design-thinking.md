# Design Thinking

**External framework · revisión: 2026-11-09**

| Campo | Ficha |
| --- | --- |
| Autoría / referencia | Tradición de diseño centrado en personas; referencia seleccionada: IDEO |
| Fuente oficial | [Design Thinking](https://www.ideo.com/methodology/design-thinking) |
| Propósito | Explorar necesidades y probar soluciones de forma iterativa. |
| Pregunta ejecutiva | ¿Estamos resolviendo el problema adecuado para las personas? |
| Entradas | Observación, entrevistas, restricciones e hipótesis. |
| Entregables / alcance | Problema reformulado, ideas, prototipos y aprendizaje. |
| Requisitos | Acceso a usuarios y capacidad de probar hipótesis. |
| Limitaciones | No tiene un único propietario ni una secuencia universal. IDEO es una referencia, no la autoría exclusiva de toda la disciplina. |
| Licencia / reutilización | Los materiales de IDEO mantienen sus derechos y términos; no se copian canvases o ilustraciones. |

Deseabilidad, factibilidad y viabilidad sirven como lentes, no como prueba de equivalencia entre frameworks.

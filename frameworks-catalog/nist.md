# NIST AI RMF

**External framework · revisión: 2026-11-09**

| Campo | Ficha |
| --- | --- |
| Autoría / referencia | National Institute of Standards and Technology (NIST) |
| Fuente oficial | [NIST AI RMF](https://www.nist.gov/itl/ai-risk-management-framework) |
| Propósito | Estructurar gestión voluntaria de riesgos de IA. |
| Pregunta ejecutiva | ¿Qué daños, controles y evidencias debemos gestionar? |
| Entradas | Contexto de uso, afectados, riesgos y capacidades de evaluación. |
| Entregables / alcance | Registro de riesgos, responsables y decisiones de tratamiento. |
| Requisitos | Participación de negocio, usuarios y especialistas; evaluación durante el ciclo de vida. |
| Limitaciones | No es una certificación ni garantiza cumplimiento. Se referencia AI RMF 1.0; la página indica que está en revisión. |
| Licencia / reutilización | Consultar avisos de NIST y de cada recurso, incluidos elementos de terceros; no se redistribuye la publicación. |

Usar para ampliar la supervisión del flujo, sin reducirlo a una lista de aprobación final.

Relaciones: consultar los IDs que incluyen este marco en la [matriz comparativa](../frameworks-mapping/README.md). Los entregables se describen como orientación de uso, no como una plantilla oficial reproducida.

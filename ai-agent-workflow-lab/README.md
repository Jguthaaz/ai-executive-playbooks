# AI Agent Workflow Lab
**Status: Work in Progress · v0.1 · October 2026 · Design only**

Explore how a bounded AI-assisted workflow could prepare an executive co-creation workshop while preserving evidence, human judgment and approval.

[Workflow specification, synthetic walkthrough and reusable worksheet](workflow.md)

## Scope
Inputs: an approved business brief and source pack. Outputs: a draft agenda, opportunity questions, evidence gaps and a facilitator review checklist.

The first version specifies an orchestrated workflow with distinct roles. It does not implement autonomous agents, tool calls, integrations or running software. There is no selected model or framework and no runtime test has been performed.

## Professional relevance
The artifact connects AI experimentation to business workflow design: task boundaries, input/output contracts, human review, failure handling and evaluation. It does not establish agent engineering proficiency or production deployment experience.

**Next increment:** manually rehearse the specification on synthetic cases and publish actual observations, then decide whether implementation adds value over a reusable prompt or checklist.

Prepared with AI assistance. No client information, actual workshop outcomes or model reliability results are claimed.

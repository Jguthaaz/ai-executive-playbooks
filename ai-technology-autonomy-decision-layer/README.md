# AI Technology & Autonomy Decision Layer v0.1
**Work in Progress · original AI-assisted synthesis · November 9, 2026**
**Evidence status:** documentation and synthetic arithmetic checks only. No client validation, deployed solution, model evaluation or business results.

Select a proportionate solution for one already-prioritized opportunity. This layer sits between opportunity prioritization and pilot design. It does not rank a portfolio or approve investment automatically.

## Use in sequence
1. Complete the [Technology Decision Canvas](technology-decision-canvas.md).
2. Follow the [Solution Selection Tree](solution-selection-tree.md); retain simpler alternatives.
3. Compare architectures with the [Architecture Trade-off Scorecard](architecture-trade-off-scorecard.md).
4. Record the conditional recommendation in the [Executive Decision Brief](executive-decision-brief.md).
5. Transfer the accepted scope to the existing [pilot brief](../templates/pilot-brief.md) and record authority in the [decision log](../templates/decision-log.md).

Read the [worked quotation decision](case-quotation-decision.md), its [synthetic inputs](case-scorecard.json), [sources and attribution](SOURCES.md), and [validation record](VALIDATION.md).

## Boundaries
RAG is a grounding pattern; a copilot is a human interaction pattern; an agent chooses steps/tools toward a goal. These can coexist and are not mutually exclusive product categories. Separate capability, grounding, orchestration and action authority before comparing configurations.

All weights, autonomy levels and thresholds here are local working conventions, not Microsoft standards. Product selection, regional availability, licensing, security and legal suitability require a separate current review. The method has not been validated with clients.

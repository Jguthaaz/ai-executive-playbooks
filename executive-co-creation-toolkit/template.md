## Agenda — 90 minutes
0–10 frame; 10–25 map friction; 25–40 create alternatives; 40–55 canvas; 55–70 prioritize; 70–82 define discovery; 82–90 decide and close.
Capture silent input before group discussion. Ask: what could disprove our view, what simpler option exists, and what evidence would change the decision?

## Prioritization
Agree anchors before scoring. Default favorable 1–5 scale: value (local convenience to strategic contribution), feasibility (major dependencies to ready inputs), learning (little insight to testing a critical assumption). Use 3 for the defined midpoint, 2 and 4 for intermediate judgments. Adapt and document specific anchors.
Default weights: value 40%, feasibility 35%, learning 25%; total 100%. Total = sum(weight × score). Unknown inputs stay unscored. Check gates separately.

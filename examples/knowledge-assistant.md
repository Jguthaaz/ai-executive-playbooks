# Worked Example: Internal Knowledge Assistant
**Status:** fictional illustration. No client, deployment, test or measured result is represented.

## Problem and decision
A fictional operations team reports difficulty finding approved guidance across internal documents. The decision is whether to test a knowledge assistant or improve document organization and search.

**Known in the scenario:** documents exist and users report search friction.
**Unknown:** baseline search time, document quality, access permissions, error rate, operating cost and user demand. These are scenario assumptions, not observations from a real organization.

## Options
| Option | Potential benefit | Key uncertainty |
| --- | --- | --- |
| Improve taxonomy and conventional search | Easier discovery with lower complexity | Whether discovery is the main problem |
| Curated FAQ | Consistent answers to recurring questions | Coverage and maintenance |
| AI assistant with source references | Natural-language access to approved content | Accuracy, permissions and cost |

## Proposed first experiment
1. Confirm the problem with representative users and establish a baseline.
2. Use a small approved document set and synthetic questions.
3. Compare current search, improved search and the assistant on identical tasks.
4. Have the process owner assess correctness, source relevance and error severity.
5. Set thresholds and resource limits before running the experiment.

Exclude sensitive content. Require source references and human review. Stop if permissions cannot be enforced or material errors cannot be controlled.

## Illustrative decision
**Investigate first.** Evidence is insufficient to choose an AI pilot. Clarify document ownership, access control and the baseline before selecting an approach.

## Results
**Not run.** There are no performance figures or business impact claims. The example demonstrates framing, alternatives and an evidence plan.

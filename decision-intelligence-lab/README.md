# Decision Intelligence Lab
**Status: Work in Progress · v0.1 · October 2026**

A transparent, documentation-first exercise in deciding which AI initiative deserves the next increment of investment.

## Executive brief
A fictional B2B services company can investigate one initiative. A weighted model compares commercial value, productivity, readiness, control feasibility and pilot affordability. Sensitivity analysis shows how the preferred alternative changes with executive priorities and uncertain assumptions.

**Illustrative conclusion:** request triage and process standardization tie in the base case. That tie does not justify immediate AI investment. Validate assumptions and compare rules with AI before releasing a pilot tranche.

This is a hypothetical portfolio exercise using entirely synthetic inputs. It is not a real investment recommendation, client case, completed pilot or evidence of financial returns.

## Start here
1. [Worked investment decision](exercise.md) — alternatives, assumptions, criteria, scoring, sensitivity, risk register and conditional decision.
2. [Synthetic scoring inputs](data/synthetic-scores.csv) — the exact scores and rationale used in the example.
3. [Reusable decision record](template.md) — adapt the logic without inheriting the fictional conclusion.

No code, model execution or installation is required. Calculate totals manually or in a spreadsheet. CSV is an optional convenience, not measured data.

## How this differs from the existing portfolio
The earlier [impact and effort case](../experiments/01-ai-opportunity-prioritization.md) keeps those two dimensions separate. This lab instead explores an explicit, compensatory investment preference model, a non-AI alternative, funding gates and weight sensitivity. Its scores are a separate synthetic dataset and are not comparable to the earlier case.
The [Executive Co-Creation Toolkit](../executive-co-creation-toolkit/README.md) can frame candidates before this investment discussion.

## Evolution
- **Now:** a Markdown decision model, reproducible arithmetic and a synthetic CSV.
- **Next:** challenge anchors and priorities with reviewers; record why scores change.
- **Later:** add a spreadsheet or code only if it improves traceability. Replace assumptions with approved evidence before making real decisions.

Prepared with AI assistance. No confidential data, real returns, implementation results or tool-specific proficiency are claimed.

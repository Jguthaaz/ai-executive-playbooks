# Explore by Decision Journey

**Comparative analysis · recorridos opcionales.** Entrar donde esté la decisión actual y volver atrás si falta evidencia. Gobierno y medición acompañan todos los pasos. No son etapas oficiales de una metodología integrada.

## De una oportunidad a un piloto defendible

| Paso / pregunta | Frameworks y relación | Evidencia que pasa al siguiente paso | Activo práctico |
| --- | --- | --- | --- |
| 1. Entender el problema | Design Thinking o LUMA; R05–R07 | Usuarios, fricción, flujo y alternativa actual | [Workshop-in-a-Box](../tools-and-templates/README.md#executive-workshop-in-a-box) |
| 2. Priorizar | CAF + Microsoft Phase 1; R01 | Un expediente de valor, deseabilidad y factibilidad; incertidumbre visible | [Opportunity Portfolio](../tools-and-templates/README.md#ai-opportunity-portfolio-navigator) |
| 3. Rediseñar y elegir | A.G.E.N.T. Audit/Gauge/Engineer + Lean + Microsoft; R02–R04, R10 | Flujo, requisitos, alternativa sin IA, autonomía y decisión técnica | [Agent or Not](../tools-and-templates/README.md#agent-or-not-decision-navigator) |
| 4. Estimar valor incremental | A.G.E.N.T. Gauge/Track; comparación local | Línea base, costos, sensibilidad y propietario del beneficio | [Business Case](../tools-and-templates/README.md#ai-business-case-simulator) |

## ¿Necesitamos realmente un agente?

Comenzar con problema y flujo observado → probar simplificación/automatización determinista → considerar recuperación de conocimiento o asistencia → justificar herramientas y autonomía solo si son necesarias. [Microsoft](../frameworks-catalog/microsoft-ai.md) aporta el filtro; [Lean](../frameworks-catalog/lean.md) el comparador de proceso. Documentar permisos, errores y aprobación humana antes de elegir plataforma. [Agent or Not](../tools-and-templates/README.md#agent-or-not-decision-navigator) enlaza el PR existente sin asumir que está fusionado.

## ¿Escalar, corregir o detener?

Revisar línea base y calidad de evidencia → comparar resultado incremental y costos completos → revisar incidentes, adopción y capacidad operativa → decidir con propietario y fecha. Un promedio favorable no compensa un fallo crítico. [NIST](../frameworks-catalog/nist.md) y [CAF](../frameworks-catalog/caf.md) acompañan la evaluación; [ISO/IEC 42001](../frameworks-catalog/iso42001.md) añade perspectiva organizacional cuando corresponda. Sin evidencia suficiente, mantener la decisión pendiente.
